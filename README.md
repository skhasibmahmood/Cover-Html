# HTML Fundamentals | Learning & Practice

A practical HTML learning repository documenting my completion of a 22-lesson HTML course, including coding exercises and a final practical implementation.

This repository is part of my journey toward becoming a **UI/UX Engineer**, with a focus on understanding the technical foundations behind digital interfaces.

## Learning Overview

- **Course:** HTML Full Course (22 Lessons)
- **Technology:** HTML5
- **Code Editor:** Visual Studio Code
- **Version Control:** Git & GitHub
- **Status:** Completed

## Topics Covered

- **HTML Fundamentals:** Document structure, elements, tags, attributes, and nesting.
- **Text Formatting:** Headings, paragraphs, `small`, `sub`, `sup`, `pre`, and line breaks.
- **Semantic Elements:** `blockquote`, `abbr`, `q`, `address`, and `cite`.
- **Links & Media:** Anchor (`a`) and image (`img`) elements with `href`, `src`, and `alt` attributes.
- **Tables & Forms:** Table structures, rows, cells, labels, and input elements.
- **Content & Layout:** `div`, `span`, `hr`, and HTML entities such as `&nbsp;`.
- **Basic Styling:** `color`, `background-color`, `font-size`, `font-family`, and text alignment.

*Also explored legacy HTML features such as `marquee` and the `align` attribute for learning purposes.*
